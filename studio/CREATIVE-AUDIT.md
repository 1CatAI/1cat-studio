# 创作画布缺陷审计 · 2026-09-08

审计基线为八卡机已安装的 `0.4.0-03a8df6dae`。修复在独立源码副本、隔离数据库、
CPU 素材服务和软件渲染 Chromium 中进行，不启动模型，不修改显卡或外部任务。

## 已修复的问题

| 问题 | 修复及验证 |
| --- | --- |
| 保存尚未返回时继续修改提示词，生成可能使用旧内容 | 所有保存调用共享一次完整的待保存队列，生成等待最新版本写入；浏览器延迟响应复现通过 |
| 字段校验失败后，修改正确仍不能自动保存 | 正确区分字段错误与版本冲突，编辑后恢复自动保存；空标题修正回归通过 |
| 撤销生成结果，轮询又把它加回画布 | 撤销/重做保留结果已放置记录，素材仍留在任务历史；等待多轮轮询确认不再出现 |
| 参数面板按钮的空格键被画布拦截 | 只消费在画布内发起的平移按键，原生按钮保留键盘行为 |
| 服务短暂掉线后一直显示失败 | 使用可恢复的连接中断状态，健康监测继续重试 |
| 较早的失败健康检查覆盖较新的停止、编辑或删除 | 写入前同时比对服务配置和实例状态；覆盖三种并发状态改变 |
| 有生成任务时拒绝停止，却把健康服务标成失败 | 操作失败与实例健康分开，保留原服务状态 |
| 停止检查完成后仍能插入新的生成任务 | 停止状态更新与任务接纳通过数据库事务互斥，提交时重新核对配置与画布版本 |
| 加载/停止排队期间允许编辑或删除服务 | 活跃生命周期任务保护配置；退出的工作进程会被核对释放，避免永久锁住 |
| 组件文件丢失或截断仍显示已安装，无法重新下载 | 按清单核对文件和大小，失效组件重新提供下载；不在轮询中反复读取巨大权重做哈希 |
| 取消还未执行的操作，把运行中的服务标为失败 | 排队取消保留原实例；实际新建实例的加载取消继续由自身执行清理 |

第二轮同时确认：连接中断的本地服务仍须停止后才能编辑/删除；不能因为新增
“连接中断”状态而绕过原有的实例保护。
