## 保留的产品能力

统一“对话”入口，在顶部切换聊天 / Agent；保留各自的草稿、历史位置、
项目选择和后台任务。模型管理、ModelScope 下载、环境管理、服务指标、
独立 GPU 功耗控制和创作画布沿用既有实现。

状态切换采用 200 ms 动效，文字与代码保留柔和流式显示。代码预览、
Agent 项目文件与任务恢复仍属于这一基线。

[对话整合验收](../CONVERSATION-AUDIT.md)记录了 14 个前端测试、类型检查、

部署没有调节显卡、切换驱动或中断外部虚拟机。

## 下一轮视觉升级

下一版将整体调整配色、字体层级、留白、布局和组件样式，覆盖对话主界面、
Agent、模型库、服务、性能与能效及创作画布。先确定主界面视觉方向，再形成
深浅主题共用的颜色、间距、圆角、状态和动效规范，逐页落实。

保留此处记录的功能与数据兼容性；运行模型、测速、任务和硬件操作不应受到
视觉修改影响。新视觉方向尚未确定，本记录不把任何候选效果稿标记为已上线。
