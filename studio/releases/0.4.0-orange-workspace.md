# Floating navigation and orange workspace

Studio now uses an 80 px navigation rail with a 56 px floating capsule, a centered Chat / Agent switch and coordinated black, white and orange themes. Existing theme selection, routes, model controls, projects and background tasks are retained.

History is closed by default. Its 304 px drawer supports search, chat pins, imports and new conversations; Agent history also supports search. At desktop widths of at least 1280 px, history can be pinned beside the workspace. Narrow windows use an overlay and restore the pinned preference when widened. Selecting a history entry closes only an unpinned drawer. Mobile navigation uses an accessible modal menu.

Chat and Agent have compact, left-aligned welcome groups and retain their existing composer during history/preview layout changes. The header responds to available workspace width; a narrow conversation beside a wide preview compacts its own controls. All pages, dialogs, canvas surfaces and login use the shared theme. Styles are organized as theme tokens, shell, shared components and page rules.

Interaction durations remain 160/200/220 ms, with independent 280 ms streaming animation. Background sampling does not animate whole message trees or change token/latency calculations. Reduced-motion preferences, keyboard focus, preview isolation and stable bottom statistics remain enforced.

Browser state additions are `onecat:history-open` (session) and `onecat:history-pinned` (local preference). History searches are session scoped. There is no database migration.

Validation covers the targeted unit tests and CPU browser suites for Chat, Agent, canvas, history, downloads, failures, motion and private source access. `design-qa.md` records the two visual/interaction audit passes. Deploy with `ONECAT_AUTO_GPU_ACTIONS=0`, retain the previous installation and installer backups, and use the bundled rollback script if needed; this update does not require loading models or changing GPU settings.
